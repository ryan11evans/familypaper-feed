# familypaper-feed

The shared, kid-friendly daily content for the **Family Paper: Daily Printable** iOS app: three short news stories, a fun fact, a joke, and a riddle.

- Feed URL: https://ryan11evans.github.io/familypaper-feed/feed.json
- App privacy policy: https://ryan11evans.github.io/familypaper-feed/privacy.html · Terms of Use: https://ryan11evans.github.io/familypaper-feed/terms.html
- Updated once each morning (Pacific time). Every family gets the same file; it contains no personal or family information.
- The app reads it with a plain HTTPS GET and sends nothing about its users.

## Schema (v1)
```json
{
  "schema_version": 1,
  "date": "YYYY-MM-DD",
  "news": [
    { "emoji": "🚀", "tag": "Space", "headline": "…", "body": "2–3 short sentences",
      "source_name": "NASA", "url": "https://…" }
  ],
  "fun_fact": "…",
  "joke":   { "q": "…", "a": "…" },
  "riddle": { "q": "…", "a": "…" }
}
```
Schema v2 adds optional space fillers (older app builds ignore them):
```json
  "word_of_the_day": { "word": "nimble", "meaning": "able to move quickly and lightly", "sentence": "…" },
  "this_day_in_history": "One kid-friendly sentence.",
  "did_you_know": "A second short fact."
```
Limits: word ≤ 24, meaning ≤ 90, sentence ≤ 140, history/did-you-know ≤ 180 characters.

`sports.json` (schema v1): public scores/schedules, generated by `tools/publish_sports.py` from ESPN's public JSON.
Per team: `last` = most recent completed game within 120 days (incl. preseason, marked `"preseason": true`; `start_utc` added so apps can say "yesterday"/"Sat"),
`next` = next game within 21 days (`"opener": true` for a regular-season opener), and an optional one-line,
deterministic, kid-safe `blurb` (≤ 60 chars: star of a game in the last 4 days > record/win streak/standing >
"first game of the season" > none). `record` is an extra raw string. All additions are optional keys, so older
app builds (≤ 12) decode it unchanged; the script validates that shape before writing and refuses to write otherwise.

`news` has 1–3 items; `url` is optional. Unknown keys are ignored by the app; `schema_version` changes only for breaking changes.

Stories are rewritten for young readers from reputable outlets (AP, NASA, MLB.com, …) and checked to be kid-safe: no politics, crime, war, disasters, or scary stories.
